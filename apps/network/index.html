About

How Network fits in My Space

Network is a platform service for host connectivity. the place to see whether My Space can reach the internet, which adapter is active, and which ports are listening. It is not a desktop tile and not a replacement for Windows Settings.

Status

Shows online/offline for this host, primary IPv4, gateway, DNS, and media hint (Wi‑Fi or Ethernet when known). Reachability probes DNS and key hosts that Matter for My Space: general internet, Microsoft connectivity, Gemini API hostname, and GitHub.

Adapters

Lists Windows network adapters with IPv4/IPv6, MAC, link speed, gateway, and DNS. Prefer this page when diagnosing “which interface am I on?” System Info still has a denser diagnostic dump if you need every raw field.

Ports

Scans TCP/UDP endpoints via netstat and maps PIDs to process names. Default filter is listening ports. useful for Bridge, Remote Hub, and local servers.

Related services

  • Remote Hub : peer online checks on the subnet
  • System Info : deeper hardware/network diagnostics
