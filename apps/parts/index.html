About Parts

A forge for clean, reusable modules — GitHub between apps.

What it is

Parts is a forge of real reusable modules extracted from My Space apps — OHLC analytics, SRS scheduling, timezone meeting slots, file classifiers, and more. Adopt them to build new apps without rewriting the same engines.

Clean by design

Canonical code lives in shared/parts/. Source stays free of host-app identifiers. Publisher credit is catalog metadata only.

Link series

  • MSL — live capability calls
  • Parts — reusable code modules
  • Pulse — cross-app messages

Layout

  • Shared forge: shared/parts/<id>/
  • Publish from any app: apps/<app>/parts/<id>/
  • Adopt dest: apps/<target>/parts/<id>/

Shell

parts(list)
parts(get finance.ohlc)
parts(adopt cards.srs into notes)
parts(publish)
parts(panel)
