About Scheduler

White-series OS time runtime — beside Jobs, not a branded series.

What it is

Scheduler owns when work runs. Jobs owns capacity and the queue. Shell when rules stay event-based. Scripts and the shell use the same schedule(…) verbs as this page.

Triggers

  • every — interval (15m, 1h, 1d)
  • daily — local clock HH:MM
  • in / at — one-shot relative or ISO
