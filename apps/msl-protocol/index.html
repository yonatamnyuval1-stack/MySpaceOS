About MSL

My Space Link: the Link-series capability bus.

What it is

Apps publish capabilities. You mint portable msl:v1/… keys, save them, and inject them into AI surfaces so models get live tools and facts, without hard-coding host IDs into every app.

Link series

  • MSL — live capability calls
  • Parts — reusable code modules
  • Pulse — cross-app messages
