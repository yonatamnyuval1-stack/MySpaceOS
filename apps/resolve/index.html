Resolve — OS troubleshooting for My Space apps

Fault watches process / IPC / renderer boundaries and maps failures onto universal kinds (LOAD_FAILED, SAVE_FAILED, NETWORK, RUNTIME…). Resolve matches a playbook (app.KIND or *.KIND) and lets you apply safe fixes (e.g. restore from .bak).

  • Fault — automatic capture + kind detection
  • Report — incident + Pulse event + bell on errors
  • Ask — sync playbook lookup without inbox noise
  • Apply — run a playbook step on an open incident
